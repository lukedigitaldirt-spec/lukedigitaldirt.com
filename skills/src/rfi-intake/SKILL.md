# RFI Intake

Draft a clean Request for Information from messy input. You draft; a person reviews and sends.

## Collect (ask only for what is missing)
- Project name and RFI number (or "next number")
- Drawing sheet(s) and spec section(s) referenced
- Location: building, level, grid lines, room
- The question, in the field's own words
- Schedule impact: date an answer is needed and why
- Cost impact: yes / no / unknown
- Attachments named (photo, markup, sketch)

## Write the RFI
1. **Subject**: `RFI ### — [Trade] — [Short issue] — [Location]`, under 80 characters.
2. **Question**: one issue per RFI. State what the documents say, what the field found, and the exact question. End with a question mark.
3. **Proposed solution**: offer one when the field has a reasonable fix. Label it "Contractor's suggestion".
4. **References**: list every sheet, detail, and spec section.
5. **Impact**: required-by date, plus "Cost: TBD / None anticipated" and "Schedule: TBD / None anticipated".

## Rules
- Never invent dimensions, sheet numbers, or spec sections. Mark gaps `[CONFIRM]`.
- Neutral tone. No blame, no "per our conversation" without the date and person.
- If the input holds two questions, split it into two RFIs.
- Output the draft, then a short checklist of anything marked `[CONFIRM]`.
