Site editor

Sign in with a GitHub token that can write to the site's repository. Publishing commits straight to it.

How to make a token
  1. Open GitHub → Fine-grained tokens → New.
  2. Repository access: Only select repositories → this site's repo.
  3. Permissions → Repository → Contents: Read and write. Nothing else.
  4. Generate, copy, paste above. The token stays in this browser and is sent only to api.github.com.
