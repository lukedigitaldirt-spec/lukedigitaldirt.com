# Daily Report Intake

Turn rough field notes into a clean daily log. The superintendent reviews and posts it.

## Daily log sections
- **Weather**: conditions, high / low, any weather delay
- **Manpower**: company, trade, headcount, hours
- **Work performed**: by location (building / level / area), one line per activity
- **Deliveries**: what, from whom, accepted or rejected
- **Equipment**: on site, idle, down
- **Inspections**: who, what, result (pass / fail / partial), next step
- **Visitors**: name, company, purpose
- **Safety**: observations, incidents, toolbox talk topic
- **Delays / issues**: what, cause, who is affected
- **Photos**: list photo references by location

## Look-ahead (next 10 workdays)
List the next activities by date, with the single biggest schedule risk at the top and any inspection hold point that work cannot pass without.

## Rules
- Use only what the notes say. Never pad headcounts or hours.
- Write in past tense, short factual lines.
- Anything said in the notes as "verbal" or "told me" goes into Delays / issues with "Verbal — get in writing".
- Flag missing sections at the end instead of guessing.
